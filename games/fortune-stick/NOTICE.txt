เซียมซีอาหาร (Fortune Stick) — ที่มาและสถานะสิทธิ์การใช้งาน
=========================================================

ไฟล์ในโฟลเดอร์นี้มาจากแพ็กเกจ "fortune-stick-mobile-celebration (1).zip" ที่ผู้ใช้ส่งมา
ตามเอกสาร README/MANIFEST ในแพ็กเกจนั้น:
  - โค้ด (fortune-stick.js, fs-random/i18n/audio/effects/confetti.js, fortune-stick.css) ถูก "พอร์ต" จากโค้ดต้นฉบับของหน้า fortune-stick ของเว็บ SpinAName
  - เสียง 3 ไฟล์ (assets/audio/*.mp3), ภาพกระบอก (assets/svg/fortune-cylinder.svg) และฟอนต์ (assets/fonts/*.woff2) เป็นไฟล์ byte-identical ที่เก็บจาก HAR ของหน้าต้นฉบับ
  - fs-motion.js (เขย่าโทรศัพท์) เป็นส่วนที่เขียนเพิ่มในแพ็กเกจนั้น ไม่ใช่ของต้นฉบับ

สิ่งที่ตัดออกเมื่อนำมาใช้ใน Wan Wan: demo (index.html/demo.js/demo.css), tools/*.py, MANIFEST.txt, README.md,
fs-audio-data.js (สำเนา base64 ของ mp3 ไว้สำหรับ file:// เท่านั้น — ใน https ใช้ไฟล์ mp3 จริง)

การแก้ไขในโค้ดต้นฉบับ (จุดเดียว) — js/fortune-stick.js:
  เพิ่มตัวเลือก showRemoveWinner (ค่าเริ่มต้น true = พฤติกรรมเดิม) เพื่อซ่อนปุ่ม "ลบผู้ชนะออก" ในโมดัลผลลัพธ์
  เพราะรายการอาหารถูกจัดการโดย Wan Wan (ค้นหา "WAN WAN LOCAL CHANGE")
ข้อความไทยของโมดัล ("ยินดีด้วย!" → "มื้อนี้ต้อง…", "ปิด" → "ตกลง") เปลี่ยนจากโค้ดของ Wan Wan ตอนโหลด ไม่ได้แก้ไฟล์ i18n

ไม่มีการเรียกเครือข่ายภายนอก/tracking/CDN

==========================================================
รีดีไซน์ระบบเซียมซี (Wan Wan v17) — สิ่งที่เปลี่ยน
==========================================================
ไฟล์ใหม่: js/fs-physics.js (ฟิสิกส์), js/fs-art.js (กราฟิก), assets/svg/fortune-cylinder-back.svg
ไฟล์ที่แก้: js/fortune-stick.js (สร้างไม้ / ลูปเฟรม / การปล่อยไม้ / รีเซ็ตรอบ),
            css/fortune-stick.css (ใช้ตัวแปรสีของ Wan Wan โดยมีค่าเดิมเป็น fallback + โหมด .fs-compact จอเตี้ย),
            assets/svg/fortune-cylinder.svg (สร้างจากตัวสร้างเดียวกับเอนจิน = ชั้นหน้า)
ไม่ได้แก้: fs-random / fs-i18n / fs-audio / fs-effects / fs-confetti / fs-motion, เสียง, ฟอนต์

ภาพกระบอกและไม้ชุดนี้วาดใหม่เป็นงานของโปรเจกต์นี้เอง (ไม่ใช้ภาพจาก HAR ของเว็บต้นฉบับอีกต่อไป)
เสียง ฟอนต์ และโค้ดส่วนที่เหลือยังเป็นของที่มาจากแพ็กเกจเดิม — ข้อสงวนเรื่องสิทธิ์ด้านบนยังใช้กับส่วนเหล่านั้น

พฤติกรรมที่เปลี่ยนโดยตั้งใจ
- ไม้ที่ตกคือหนึ่งใน 35 แท่งในกระบอก (เดิมเป็นวัตถุแยกที่โผล่ขึ้นมาใหม่); รอบใหม่ไม้กลับเข้ากระบอกและสุ่มแท่งนำใหม่
- ไม้ตกด้วยฟิสิกส์จนนิ่งเองก่อนเปิดโมดัลผล (ใช้เวลานานกว่าเดิมเล็กน้อย ~1–2 วินาที); มีตาข่ายนิรภัยไม่ให้ค้าง
- เสียงเขย่าผูกกับการชนจริงแทนการสุ่มต่อแท่ง
คงเดิม: สถานะ shaking/dropping/zooming/revealed, การสุ่มผลและการส่ง event, วิธีควบคุม (ลาก / กดค้าง / เขย่าโทรศัพท์), API สาธารณะ

ลายบนกระบอก (v19): ตัวเลือก pattern ตอนสร้าง  new FortuneStick({ ..., pattern: 'lattice' | 'lotus' | 'cloud' })
  lattice = ลายประจำยามวนรอบกระบอก (ค่าเริ่มต้น), lotus = ดอกไม้ในเหรียญกลม, cloud = ลายเมฆ
  หากต้องการเปลี่ยนในเว็บ ให้เพิ่ม pattern ในอ็อบเจ็กต์ที่ index.html ส่งให้ new FortuneStick(...)
  ทุกครั้งที่แก้ไฟล์ .js/.css/.svg ต้องเปลี่ยนเลข CACHE_NAME ใน service-worker.js (ไฟล์เหล่านี้เป็น cache-first)
